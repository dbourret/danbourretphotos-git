DABOPHOTOS PRIVATE GALLERIES — RESTORATIONS UPDATE
=================================================

WHAT THIS UPDATE ADDS
---------------------
- A Restorations card on the existing private landing page.
- A new private page at:
  https://danbourretphotos.com/private-dabo-8q4m2/restorations/
- 31 restoration groups and 93 full-size images.
- Each group is ordered exactly as:
  1. Original JPG
  2. Restored PNG
  3. Combined
- The groups themselves are sorted by filename.
- A full-screen viewer with previous/next arrows, keyboard navigation,
  Escape-to-close, and mobile swipe navigation.
- Smaller thumbnails for faster gallery loading; the full-size source image
  opens only when selected.

UPLOAD INSTRUCTIONS
-------------------
This ZIP is an UPDATE for the folder already online.

1. In Hostinger File Manager, open your public_html folder.
2. Upload private-dabo-8q4m2-restorations-update.zip into public_html.
3. Extract it in public_html.
4. Allow it to merge with and overwrite files in the existing folder named:
   private-dabo-8q4m2
5. Do not delete the existing sports, cars, images/sports, images/cars, or
   assets/private.css files. They are not included in this update ZIP.
6. Open this address and refresh the page:
   https://danbourretphotos.com/private-dabo-8q4m2/
7. Click Restorations to test the new page.
