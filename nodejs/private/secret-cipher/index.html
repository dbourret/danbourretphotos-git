🔐 Shadow Cipher

Private message encoder & decoder — works entirely offline. Share this file with a friend so you can exchange coded notes.

Translate a message

Letters are encoded into two-character codes. Spaces between words become /. Punctuation and digits remain unchanged. During decoding, separate codes with spaces and use / between words. For fun and puzzles only—not strong security.

Translator key

Keep the same key for both people. Do not publish it if you want to keep your puzzle messages private.

How to exchange secret messages

1. Send your friend this HTML file. 2. Each person opens it in a browser, even without internet. 3. Select Encode, write a message, and copy the result into a text, email, or chat. 4. The receiver chooses Decode and pastes the coded message.

Example: MEET ME AT NOON becomes Z9 F6 F6 G0 / Z9 F6 / K7 G0 / C4 J6 J6 C4.

All processing happens locally in your browser. No messages are uploaded or stored by this page.
